# 隐私政策 PIPL 合规审查框架

## 审查提示词

以下为完整的审查提示词，可直接用于对隐私政策进行逐项审查：

```
你是一名资深个人信息保护合规审查专家，精通《中华人民共和国个人信息保护法》（PIPL）及相关国家标准（GB/T 35273-2020）。请对以下隐私政策/隐私协议进行全面审查，逐项输出审查结论及优化建议。

一、审查框架

请按照以下维度逐一审查，每项给出【合规/不合规/部分合规】判定及具体说明：

1. 个人信息处理者信息
   - 是否明确处理者名称（含全称）和联系方式？
   - 依据：PIPL第十七条

2. 处理目的、方式及个人信息种类
   - 是否按业务场景逐一列明收集的个人信息种类？
   - 是否说明每类信息的处理目的和处理方式？
   - 是否区分必要信息和非必要信息？
   - 依据：PIPL第十七条、第六条

3. 处理目的/方式/种类变更时的重新同意
   - 是否明确当处理目的、处理方式或个人信息种类发生变更时，将重新征得个人同意？
   - 依据：PIPL第十四条

4. 个人信息保存期限及到期处理方式
   - 是否明确各类个人信息的保存期限？
   - 是否说明到期后的处理方式（删除/匿名化）？
   - 是否明确注销账户后的数据处理规则？
   - 依据：PIPL第十九条、第四十七条

5. 个人信息主体的权利及行使途径
   请逐一检查以下权利是否明确列出，并提供具体行使途径：
   - 查询权（PIPL第四十四条）
   - 复制权（PIPL第四十五条）
   - 转移权（可携带权）（PIPL第四十五条）
   - 更正权（PIPL第四十六条）
   - 补充权（PIPL第四十六条）
   - 删除权（PIPL第四十七条）
   - 限制处理权（PIPL第四十四条）
   - 撤回同意权（PIPL第十五条）
   - 投诉举报权（PIPL第五十条）

6. 向第三方提供个人信息
   - 是否逐一列明接收方名称/姓名、联系方式、处理目的、处理方式及个人信息种类？
   - 依据：PIPL第二十三条

7. 委托处理个人信息
   - 是否说明委托处理的情形？
   - 是否说明对受托方的监督措施？
   - 依据：PIPL第二十一条

8. 共同处理个人信息
   - 是否明确声明是否存在共同处理个人信息的情形？
   - 如存在，是否约定各自的权利义务？
   - 依据：PIPL第二十条

9. 个人信息的转让
   - 是否明确转让情形及条件？
   - 是否告知接收方名称/姓名和联系方式？
   - 依据：PIPL第二十二条

10. 个人信息的公开披露
    - 是否说明公开披露的情形、目的及涉及的信息种类？
    - 是否说明公开前将开展个人信息保护影响评估？
    - 依据：PIPL第二十五条、第五十五条

11. 处理已公开个人信息
    - 是否明确说明是否存在处理已公开个人信息的情形？
    - 如存在，是否说明处理规则及个人拒绝的途径？
    - 依据：PIPL第二十七条

12. 个人信息的跨境提供
    - 是否说明是否存在跨境提供情形？
    - 如存在，是否说明跨境传输的法律依据及保障措施？
    - 依据：PIPL第三十八条、第三十九条

13. 个人信息安全保护措施
    - 是否说明技术措施（加密、访问控制等）？
    - 是否说明管理措施（制度、培训等）？
    - 是否说明安全事件应急响应机制？
    - 依据：PIPL第五十一条、第五十七条

14. 未成年人个人信息保护
    - 是否区分不满十四周岁和已满十四周岁未成年人的保护规则？
    - 是否说明需取得监护人同意？
    - 依据：PIPL第三十一条

15. 隐私政策更新机制
    - 是否说明更新情形及通知方式？
    - 是否说明重大变更将重新征得同意？
    - 依据：PIPL第十七条

16. 文本格式与可读性
    - 是否采用加粗、下划线、高亮等方式标注重点内容？
    - 标题层级是否清晰？是否便于阅读？
    - 语言是否通俗易懂，避免法律术语堆砌？
    - 依据：PIPL第十七条"以显著方式、清晰易懂的语言"

17. 联系方式
    - 是否提供客服热线、地址、在线反馈等多种联系渠道？
    - 是否说明个人信息保护负责人的联系方式？
    - 是否说明响应时限？

18. 内容重复与冲突
    - 是否存在不同章节内容重复？
    - 是否存在前后矛盾的表述？

二、输出格式

请按以下格式逐项输出：

| 序号 | 审查项 | 判定 | 合规情况 | 问题描述 | 优化建议 | 法条依据 |
|------|--------|------|----------|----------|----------|----------|
| 1 | xxx | 合规 | ... | ... | ... | PIPL第X条 |
| 2 | xxx | 不合规 | ... | ... | ... | PIPL第X条 |

三、总结

最后输出：
- 合规项数/总项数
- 高优先级整改项（涉及行政处罚风险的）
- 中优先级优化项（建议完善但不影响合规底线的）
- 低优先级建议项（锦上添花的优化建议）
```

## 法条依据速查

| 维度 | PIPL条款 | 核心要求 |
|------|---------|---------|
| 处理者信息 | 第17条 | 以显著方式、清晰易懂的语言告知处理者名称和联系方式 |
| 处理原则 | 第6条 | 处理目的明确、合理，与处理目的直接相关，采取对个人权益影响最小的方式 |
| 变更重新同意 | 第14条 | 处理目的、方式、种类变更时，应当重新取得个人同意 |
| 撤回同意 | 第15条 | 个人有权撤回同意，撤回同意不影响撤回前已处理信息效力 |
| 保存期限 | 第19条 | 保存期限为实现处理目的所必要的最短时间 |
| 委托处理 | 第21条 | 约定委托处理目的、期限、方式、种类等，受托方不得超出约定 |
| 共同处理 | 第20条 | 约定各自权利义务，共同承担连带责任 |
| 向第三方提供 | 第23条 | 告知接收方名称/姓名、联系方式、处理目的、方式、种类，并取得单独同意 |
| 转让 | 第22条 | 合并/分立/转让/破产时告知接收方名称/姓名和联系方式 |
| 公开披露 | 第25条 | 告知公开目的、信息类型，取得单独同意 |
| 已公开信息 | 第27条 | 在合理范围内处理，个人明确拒绝的除外 |
| 跨境提供 | 第38-39条 | 通过安全评估/认证/标准合同，告知境外接收方信息 |
| 敏感信息 | 第29条 | 取得单独同意，告知处理必要性及对个人权益的影响 |
| 未成年人 | 第31条 | 不满14周岁须取得监护人同意，制定专门处理规则 |
| 个人权利 | 第44-50条 | 查询、复制、转移、更正、补充、删除、限制处理、撤回同意、投诉举报 |
| 安全措施 | 第51条 | 采取必要措施确保个人信息安全 |
| 安全事件 | 第57条 | 发生或可能发生泄露时立即采取补救措施并通知 |
| 影响评估 | 第55条 | 特定情形下事前进行个人信息保护影响评估 |
